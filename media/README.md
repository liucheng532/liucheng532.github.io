# Media folders

Put new website material in the matching folder, then add its path to `data.js`.

- `HOME/` — full-width hero artwork or background video
- `ABOUT/` — portrait and personal photographs
- `RESEARCH/` — research diagrams, result GIFs, and demo videos
- `PUBLICATIONS/` — paper thumbnails and teaser images
- `PROJECTS/` — competition, hardware, and project photographs; use one subfolder per project when several files belong together
- `BLOG/` — article covers and note illustrations

Recommended image formats: `.webp`, `.jpg`, or `.png`. Keep individual web images below 2 MB when practical.
